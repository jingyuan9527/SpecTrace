# 发布前人工复核清单（T98）

> e2e 已覆盖桌面 Chromium 键盘路径与移动端视口用例（27 例），但**真机触控、读屏播报、真实网络环境**自动化替代不了。每次对外发布前按本清单过一遍，结果记录在文末表格。

## 一、真机主链路（iOS Safari + Android Chrome 各一遍）

访问地址：部署环境首页。逐项核对，异常记入文末问题表。

| # | 步骤 | 预期 |
| --- | --- | --- |
| 1 | 首页加载、下拉刷新 | 无破图、无横向滚动条；搜索框可聚焦弹出键盘 |
| 2 | 搜索联想：输入全拼（如 `pingguo`）与首字母（`pg`） | 下拉出现候选，可点选；iOS 键盘「完成」不遮挡 |
| 3 | 机型库：品牌/年份筛选、勾选 2~4 台进对比 | 勾选有反馈；底部对比栏可点；第 5 台被拦截有提示 |
| 4 | 对比页：查看差异高亮、开/关「仅显示差异」、折叠分组 | 表格横向可滚动；差异行底色与色条清晰 |
| 5 | 对比页：生成 AI 差异摘要 | 有额度时出结果；超限/未配置模型时入口隐藏或有明确提示 |
| 6 | 对比页：复制分享链接 → 新开标签页/发给另一台设备打开 | 还原同组机型对比表 |
| 7 | 对比页：社媒导出 → 下载模板卡（竖版/横版） | 图片保存成功，内容完整带水印 |
| 8 | 机型详情：参数分组、存储版本价格表、参数行「来源/更新于/N 人待核实」 | 布局单列不溢出；长参数值正常换行 |
| 9 | 机型详情：参数行「报告参数错误」提交纠错 | 拿到随机编号回执；凭编号查询显示「待处理」 |
| 10 | 系列趋势：切换跨代/同代、点参数卡聚焦大图、一键全部加入对比 | 图表可交互；跳转对比页带入机型 |
| 11 | 导航与页脚：移动端菜单收进 Sheet、页脚「管理入口」 | 主导航无「后台」项；Sheet 开合顺畅 |
| 12 | 暗色模式：系统切深色 | 全站无白底残留、无浅色文字消失 |
| 13 | PWA：Safari「添加到主屏幕」/ Chrome「安装应用」 | 图标出现，打开为独立窗口；离线开过的页面有缓存 |
| 14 | 返回手势（iOS 边缘滑动 / Android 返回键） | 不跳出站、不丢对比池状态 |

## 二、读屏走查（iOS VoiceOver + Android TalkBack）

重点覆盖两个表单场景，逐屏听播报：

| # | 场景 | 预期 |
| --- | --- | --- |
| 1 | 登录页（`/admin/login`）：用户名/密码框、登录按钮 | 每个控件有可理解的播报（标签而非裸数字）；错误提示（密码错误/锁定）能被播报 |
| 2 | 登录成功 → 强制改密页（用初始密码账号） | 三输入框标签清晰；改密成功跳转后台 |
| 3 | 抓取审核弹窗：打开后焦点进入弹窗、参数行 diff 播报、底部操作栏按钮 | 不播报弹窗外内容；「审核通过/丢弃」按钮可达可触发 |
| 4 | 通用弹窗关闭：Esc（桌面）/ 关闭按钮（触屏） | 关闭后焦点回到触发元素，不落到底部 |
| 5 | 对比页表格：caption 与行列播报 | 能听懂「某行某列 = 某值」的上下文 |

## 三、键盘路径（桌面辅助复核）

e2e 已覆盖：登录、新增品牌/机型、提交抓取、审核通过全程 Tab + Enter 可达。发布前人工快过一遍「登录 → 抓取审核 → 弹窗 → 通过」路径即可，有新增表单时单独走查。
